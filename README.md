# ⚡ Neon Runner 3D

Endless runner pseudo-3D de 3 carriles hecho con **HTML5 Canvas y JavaScript puro** (sin librerías),
diseñado como **Telegram Mini App**.

## 🎮 Características
- Carrera hacia adelante con esquiva en 3 carriles (estilo Subway Surfers)
- Salto, doble salto y deslizamiento · dificultad progresiva
- Gráficos neón: gemas brillantes, carretera con perspectiva y parallax urbano
- Rewarded ads con **Monetag**: gemas x2 al inicio y 2 revividos por partida
- **Ranking de amigos** sin servidor: retos por enlace profundo (`start_param`) + CloudStorage de Telegram
- Récord persistente, hápticas y pantalla adaptada a móvil

## 🕹️ Controles
| Acción | Teclado | Móvil |
|---|---|---|
| Cambiar carril | ← → / A D | Swipe lateral |
| Saltar / doble salto | Espacio / ↑ | Swipe arriba |
| Deslizarse | ↓ / S | Swipe abajo |

## 🚀 Jugar
Abre la mini app desde tu bot de Telegram o prueba el `index.html` en cualquier navegador.

## 📦 Despliegue
1. Sube este repositorio a GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
2. Pega la URL HTTPS en BotFather → Menu Button / Mini App.
3. Para monetizar: pega el snippet SDK de Monetag en el `<head>` y tus Zone IDs en `MONETAG_CONFIG`.
